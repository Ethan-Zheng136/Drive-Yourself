persona LoRAs define a style axis mixed by latent-content interpolation (`α`), the **fm3-kin
FMHead** samples N=16 dynamically-feasible candidate trajectories, and a selector returns one.

```mermaid
flowchart LR
    subgraph IN[Inputs]
        CAM[Multi-view cameras]
        EGO[Ego state]
        CMD[Navigation command]
    end

    CAM --> VLA
    EGO --> VLA
    CMD --> VLA

    VLA["AutoVLA backbone<br/>(Qwen2.5-VL-3B)<br/><i>VLA encoder</i>"] -->|context hidden tokens| MIX

    LORA["Style axis<br/>Persona LoRA adapters"] -->|styled hidden| MIX
    ALPHA["alpha = user preference (0..1)"] -.-> MIX

    MIX["Latent-content interpolation<br/>c = h_base + &alpha; (h_style − h_base)"] --> FM

    FM["<b>FMHead</b> (fm3-kin)<br/>Conditional rectified flow-matching decoder<br/>DiT + AdaLN-Zero · control-space<br/>kinematic-unicycle constraint"] --> SAMP

    SAMP["Sample N = 16<br/>candidate trajectories"] --> SEL
    SEL["Selector<br/>(PDM / learned scorer)"] --> OUT["Final trajectory"]
```

- **α axis:** `α = 0` reproduces the base AutoVLA behavior (PDMS ≈ 0.9125); increasing `α` applies
  the persona and moves the style sub-metrics (DAI/PAI/SAI, jerk, headway) — the trade-off swept in
  the table above.
- **Selector caveat:** the PDMS column uses the privileged `mode=pdm` selector and is a selection
  **upper bound**; a deployable selector (map-only / PDM-Closed forecasts / learned scorer) is the
  ongoing work.
