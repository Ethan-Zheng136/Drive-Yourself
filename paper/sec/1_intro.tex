\section{Introduction}
\label{sec:intro}

End-to-end driving models learn to map sensor inputs to a trajectory by imitating
large corpora of expert driving. The training objective rewards agreement with
the logged future, which pushes the policy toward a single consensus behavior. In
deployment this acts as one average driver: the policy has no mechanism to condition
on user preference, so it defaults to a single learned behavioral mode. This is
commonly framed as a personalization gap, but it has two consequences that can be
measured directly.

The first consequence concerns what safety scores can and cannot see. On the same scenarios,
planners that reach comparable closed-loop safety can sit far apart on a
multi-dimensional behavioral profile of speed, acceleration, jerk, headway, and
spacing (\cref{fig:teaser}). A safety-only objective therefore does not constrain
driving style, and a single safety number does not reveal where a policy sits on
that profile. The second concerns multi-modality. When several maneuvers are
equally reasonable, a model trained to match an averaged target and decoded as a
single mode tends to produce a trajectory that lies between the modes rather than
committing to one. What this paradigm collapses is not the route or the scene
response but the manner in which the motion is carried out. Driving style is not
a coarse label but a measurable and interpretable description of how a vehicle is
driven, which should follow user preference while still respecting the scene.

Prior work on personalized and stylized driving conditions imitation on a driver
profile or a discrete style label,

and its style-aware evaluation tends to fold style into the score itself. What is
missing is a formulation in which style is an explicit, continuous, and composable
axis, measured on its own terms---separately from the hard safety gates---and
produced by a decoder that can commit to a mode rather than average across equally
plausible maneuvers.

We build such a formulation on a vision-language-action (VLA) backbone and call it
YouDrive. Its core is a generative decoder: we replace the backbone's discrete
action codebook with a flow-matching decoder that samples several dynamically
feasible trajectories in a kinematic control space and commits to one, so that
equally plausible maneuvers are resolved by selection rather than averaged into a
non-committal path. On top of this decoder we expose driving style as a control
axis. We distill each persona into a low-rank adapter over the backbone, whose
weight update induces a reusable direction in the VLA content representation, and a
single coefficient then scales and composes these directions without retraining the
backbone. We define style in the VLA content space on purpose. Task-vector control
has been observed in language-grounded representations, where directions correspond
to interpretable behavior,

and we test whether a purely geometric feature space---organized around scene
geometry rather than behavior---affords the same control. Finally, we measure
style with YDMS, a measurement framework that gates hard safety and task
requirements and then scores interpretable, scenario-normalized style dimensions.

\paragraph{Contributions.}
\begin{itemize}
    \item YDMS, a driving-style metric that separates hard safety and task gates
    from interpretable, scenario-normalized style dimensions, with a variance
    analysis showing that per-driver style is a systematic signal that a single
    safety score and coarse style categories both miss.
    \item A flow-matching trajectory decoder for a VLA planner that replaces the
    discrete action codebook and resolves multi-modal scenes by committing to a
    sampled, dynamically feasible trajectory rather than averaging.
    \item A formulation of driving style as a composable task vector: a low-rank
    persona adapter whose weight update induces a scalable direction in the VLA
    content space, giving a single continuous control coefficient over style without
    retraining the backbone.
    \item An empirical study on NAVSIM showing that style forms a wide, controllable
    range while closed-loop safety is retained across per-teacher and blended
    personas---PDMS stays above 0.90 throughout---including continuous
    single-coefficient control and composition of personas.
\end{itemize}
